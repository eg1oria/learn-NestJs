## Зачем это в реальной жизни

Почти любая первая задача на новой работе выглядит так: поменяй поведение существующего эндпоинта и не сломай тесты. Чтобы её сделать, нужно найти, где живёт логика, понять цепочку «контроллер → сервис» и обновить тесты, которые описывают старое поведение.

## Что сделать

1. Запусти `npm run start:dev` в `backend/` и открой `http://localhost:3000`. Там будет `Hello World!`.
2. Сделай так, чтобы `GET /` отвечал текстом **«Добро пожаловать в Гильдию героев!»**.
3. Строка должна жить в **сервисе**, а не в контроллере.
4. Переименуй методы `getHello` в контроллере и сервисе во что-то осмысленное.
5. Обнови существующие тесты под новое поведение: `src/app.controller.spec.ts` и `test/app.e2e-spec.ts`.
6. Открой на платформе страницу **«Моя гильдия»** (`http://localhost:3001/guild`): приветствие должно появиться там «вживую».

## Критерии приёмки

- [ ] `GET /` возвращает `200` и текст, содержащий «Гильдию героев».
- [ ] Строка приветствия находится в `AppService`, контроллер только передаёт результат дальше.
- [ ] Имени `getHello` в коде больше нет.
- [ ] `npm test` зелёный (unit-тест обновлён).
- [ ] `npm run test:e2e -- app` и `npm run test:e2e -- lessons/1.2` зелёные.
- [ ] `npm run lint` и `npm run build` без ошибок.

## Как проверить самому

```bash
curl -i http://localhost:3000/
```

Ожидаемый ответ:

```http
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8

Добро пожаловать в Гильдию героев!
```

## Подсказки

### Уровень 1 — намёк

Начни с декоратора `@Get()` в контроллере: это вход в эндпоинт. Пройди от него вглубь и посмотри, кого вызывает метод контроллера.

### Уровень 2 — направление

Переименовать метод — это изменить его в трёх местах: в сервисе, в контроллере (где он вызывается) и в тесте. В VS Code это делается одной командой **Rename Symbol** (`F2`), и она сама найдёт все места.

### Уровень 3 — почти решение

Unit-тест в `app.controller.spec.ts` вызывает метод контроллера напрямую и сравнивает результат со строкой. Поменяй имя метода и ожидаемую строку. В e2e-тесте `.expect('Hello World!')` тоже нужно поменять на новую строку.

## ⭐ Звёздочка

Добавь второй маршрут `GET /motto` с девизом гильдии. Посмотри, как после этого изменился лог запуска: в нём появится новая строчка `Mapped {...}`. Объясни в чате, что она значит.
