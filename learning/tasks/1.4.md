## Зачем это в реальной жизни

У любого продакшен-сервиса есть **health-check**: эндпоинт, который отвечает на вопрос «ты живой?». Его каждые несколько секунд опрашивают балансировщик нагрузки (load balancer), Kubernetes и мониторинг. Если сервис перестал отвечать «ok», его перезапускают и перестают слать на него пользователей.

## Что сделать

1. Добавь эндпоинт `GET /health`. Он возвращает **JSON**:
   - `status` — строка `"ok"`;
   - `uptime` — сколько **секунд** работает процесс (число, можно дробное);
   - `timestamp` — текущее время в формате ISO 8601, например `"2026-11-25T18:00:00.000Z"`.
2. Логика сборки ответа живёт в **сервисе**, контроллер только делегирует.
3. Опиши тип ответа (`interface` или `type`, например `HealthStatus`) и укажи его как тип возвращаемого значения. Как это делается, разобрано в статье [про типы](/library/typescript-types).
4. `GET /` продолжает работать, как в задании 1.2.
5. Добавь запрос в `backend/requests/guild.http` и проверь им эндпоинт.

## Критерии приёмки

- [ ] `GET /health` возвращает `200` и `Content-Type: application/json`.
- [ ] `status` равен `"ok"`, `uptime` — неотрицательное число, `timestamp` — валидная ISO-строка текущего времени.
- [ ] Ответ собирается в сервисе, контроллер не содержит логики.
- [ ] Есть явный тип ответа, нигде нет `any`.
- [ ] Тесты `1.2` и `1.4` зелёные, `npm run lint` и `npm run build` чистые.

## Как проверить самому

```bash
curl -i http://localhost:3000/health
```

Ожидаемый ответ (числа будут другие):

```http
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"status":"ok","uptime":12.345,"timestamp":"2026-11-25T18:00:00.000Z"}
```

Ещё ответ можно увидеть на странице «Моя гильдия» на платформе.

## Подсказки

### Уровень 1 — намёк

Если метод контроллера возвращает **объект**, а не строку, Nest сам превратит его в JSON и выставит нужный `Content-Type`. Сколько работает процесс, Node.js знает и без тебя: посмотри, что есть у глобального объекта `process`.

### Уровень 2 — направление

`process.uptime()` возвращает секунды, а `new Date().toISOString()` даёт ISO-строку. Новый маршрут — это новый метод в контроллере с декоратором `@Get('...')`, а путь указывается аргументом декоратора.

### Уровень 3 — почти решение

В сервисе метод вроде `getHealth(): HealthStatus` собирает и возвращает объект из трёх полей. В контроллере метод с `@Get('health')` возвращает результат сервиса. Тип опиши в отдельном файле, например `src/health-status.ts`, и импортируй в обоих местах.

## ⭐ Звёздочка

Health-check нельзя кэшировать: иначе мониторинг увидит «ok» от мёртвого сервера. Найди в документации Nest, как выставить у ответа заголовок `Cache-Control: no-store`, и добавь его. Проверь через `curl -i`.
